# Jira CLI Skill

이 스킬은 프로젝트 및 터미널 환경에 이미 설치된 `jira` CLI(v1.5.0)를 사용하여 Atlassian Jira 작업을 안전하고 신속하게 수행하기 위한 가이드입니다.
**도구 존재 여부 확인(which jira 등)을 생략하고 즉시 `jira` 명령어를 실행합니다.**

---

## 1. 핵심 명령어 요약

| 동작 | 명령어 예시 | 설명 |
| :--- | :--- | :--- |
| **이슈 생성** | `jira create "<제목>" -p <프로젝트키> -t "<유형>" -d "<마크다운본문>"` | 신규 이슈(작업, 스토리, 에픽, Subtask, Bug) 생성 |
| **이슈 상세 조회** | `jira get <KEY> --md` | 설명, 하위작업, 코멘트 전체를 마크다운으로 조회 |
| **이슈 목록 조회** | `jira list [JQL] --md` (또는 `--json`) | JQL 필터링 기반 이슈 목록 조회 |
| **상태 전이 확인** | `jira transitions <KEY>` | 변경 가능한 다음 상태 목록 조회 |
| **상태 변경** | `jira move <KEY> "<상태>"` | 예: `'해야 할 일'`, `'진행 중'`, `'완료'` |
| **코멘트 등록** | `jira comment <KEY> "<메시지>"` | 진행 상황 또는 완료 코멘트 등록 |
| **이슈 수정** | `jira edit <KEY> -s "<제목>" -d "<설명>"` | 이슈 메타데이터 및 내용 수정 |
| **라벨 조회** | `jira labels` | 팀 표준 라벨 카탈로그 조회 |

---

## 2. 주요 플래그 (Flags)

- `-p, --project string`: 프로젝트 키 (예: `TP`)
- `-t, --type string`: 이슈 유형 (기본: `'작업'`, 선택: `작업`, `스토리`, `에픽`, `Subtask`, `Bug`)
- `-d, --desc string`: 마크다운 형식의 상세 설명 (자동 ADF 변환)
- `-l, --labels string`: 라벨 목록 (쉼표 구분)
- `--due string`: 마감일 (`YYYY-MM-DD`)
- `--parent string`: 상위 이슈 키 (Subtask 생성 시 필수)
- `--md, --markdown`: Markdown 문서로 출력 (LLM 프롬프트 분석 최적화)
- `--json`: JSON 구조체로 출력 (스크립트/도구 연동 최적화)

---

## 3. AI 에이전트 행동 가이드라인 (Best Practices)

1. **사전 검증 불필요**:
   - `which jira` 등의 탐색 명령을 절대 실행하지 않고 바로 `jira` 커맨드를 호출합니다.
2. **티켓 맥락 파악**:
   - 티켓의 전체 작업 내용 및 히스토리를 파악할 때는 반드시 `jira get <KEY> --md`를 사용하여 추가 호출 없이 단번에 맥락을 파악합니다.
3. **상태 변경 전 전이 확인**:
   - `jira move` 실행 전 `jira transitions <KEY>`로 전이 가능한 정확한 상태명을 확인합니다.
4. **마크다운 본문 지원**:
   - `-d` 플래그는 일반 텍스트뿐 아니라 헤딩(`##`), 불릿(`-`), 표, 체크리스트(`- [ ]`) 등 마크다운 문법을 완벽히 지원하므로 구조화된 태스크를 작성합니다.
